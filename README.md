## 🛠️ Herramientas y Tecnologías

Las principales tecnologías, lenguajes y frameworks abarcados a lo largo de los distintos módulos de esta capacitación incluyen:

* **Front-End:** HTML5, CSS3, JavaScript (ES6+), Bootstrap, jQuery.
* **Back-End (C#):** C#, ASP.NET, Arquitectura MVC.
* **Back-End (JS):** Node.js.
* **Bases de Datos:** Bases de Datos Relacionales y SQL.
* **Frameworks SPA:** Vue.js, React.js.
* **Otras Herramientas:** Git (Control de versiones), AJAX, DevTools (Chrome/Firefox).
